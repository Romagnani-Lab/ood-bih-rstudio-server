# RStudio as Open OnDemand App

An interactive Open OnDemand app that launches an RStudio Server using an Apptainer image, with R provided via conda or [pixi](https://pixi.sh).

Forked from [bihealth/ood-bih-rstudio-server](https://github.com/bihealth/ood-bih-rstudio-server), itself based on [OSC/bc_osc_rstudio_server](https://github.com/OSC/bc_osc_rstudio_server).

For colleague-facing setup instructions, see the [bih-cubi-romagnani](https://github.com/Romagnani-Lab/bih-cubi-romagnani) repository.
